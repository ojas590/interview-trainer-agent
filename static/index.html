        ℹ️ About This Project

        🏗️ Architecture

        Problem Statement: Interview Trainer Agent powered by RAG — prepares users for job interviews by generating tailored question sets and preparation strategies.


        Tech Stack:

        • 🧠 IBM Granite 3.3 8B Instruct — Core LLM for question generation, evaluation, and strategy via IBM watsonx.ai
        • 📊 IBM Slate 125M — Embedding model for semantic document retrieval
        • 🔍 FAISS Vector Store — Efficient similarity search over the knowledge base
        • 🐍 Python + Flask — Backend API server
        • 📚 RAG Pipeline — Retrieves role-specific knowledge before generating answers
        • 🌐 Vanilla HTML/CSS/JS — Responsive single-page frontend

        Knowledge Base: Curated interview questions for Software Engineers, Data Scientists, Product Managers, behavioral questions, HR questions, and industry insights — all embedded and indexed for semantic retrieval.


        RAG Flow: User profile → semantic query → FAISS retrieval → relevant docs injected into Granite prompt → personalized response generated → returned to user.

        🔑 Setup Instructions
        1. Get IBM Cloud API key at cloud.ibm.com
        2. Create a watsonx.ai project at dataplatform.cloud.ibm.com
        3. Add your WATSONX_API_KEY and WATSONX_PROJECT_ID to the .env file
        4. Run: pip install -r requirements.txt
        5. Run: python app.py
